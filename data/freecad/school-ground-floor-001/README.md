# 匿名首层建筑模型重建训练样本

从二维 CAD 及剖面资料重建 FreeCAD 首层建筑模型的真实历史执行轨迹。任务要求保留架空区及可编辑构件，并记录构建过程。保留修复过程，最终参数及几何结果见验收报告。

## 内容

- `build-trajectory.json`：有来源序号的结构化训练对话，保留调用、返回、用户约束及可见反馈。
- `training.jsonl`：单条完整会话的通用工具调用训练格式；不是针对某个训练平台承诺可直接导入的格式。
- `sanitized-records.jsonl`、`execution-details.jsonl`：脱敏后的阶段原始记录及命令/文件修改/查看图片明细。执行明细与外层结果可能重复。
- `trajectory.html`：离线展开阅读。
- `task-spec.json`：归一化任务要求，区别于原始需求文档。
- `validation.json`：历史最终验收报告，含24个洞口、参数联动、9块楼板标高、8段楼梯和STEP回读结果。
- `model-build-history.jsonl`、`repair-history.json`：阶段事件和修复证据。早期事件中的对象数是阶段数；最终统计以 `validation.json` 为准。
- `privacy-report.json`、`manifest.json`：脱敏统计与文件完整性。

## 质量与使用范围

历史最终结果：130根柱、111段墙（含门窗宿主）、10窗、14门、8段楼梯、5块地板、4块上方楼板；677个文档对象、339个实体。历史报告记录无无效形状、无草图求解错误，24个门窗洞口贯通；3900→4000毫米联动检查后恢复；STEP回读实体数一致。

保留了原生Space属性不兼容、楼板法向和标高修复。推定的门高、部分楼板边界及室外竖向尺寸均有标记。未进行施工、结构或消防合规验收。本次只整理既有记录，没有重新运行建模或冒充独立验收。

## 脱敏与复现限制

移除个人目录、邮箱、项目与位置名称、唯一会话标识、实际时间及源文件指纹；原始全局坐标清零。包含需求全文或文档元数据的输出以明确省略标记替代；部分第三方源码检查原文省略。没有原始需求全文、DWG、FCStd、STEP、图片、绝对路径映射或可逆身份映射。

局部几何尺寸、模型拓扑和执行步骤保留，因此这是身份与位置标识脱敏，不能承诺建筑形状绝对不可重识别。历史代码也可能因脱敏而无法原样重放；此包用于文本轨迹学习和过程复核，不能独立还原完整工程。历史工具已截断的输出无法恢复。

原始记录与内部推理、系统/开发者指令均未上传。`source_sequence` 仅指向本地留存的原始可见轨迹，不能解析为会话ID。不得把可见进度说明当作内部思维链。
